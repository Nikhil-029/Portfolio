# Nikhil: AI/ML Engineer Portfolio

Personal portfolio for freelance AI/ML work: agent systems, document
intelligence, and LLM infrastructure. It is a single self-contained
`index.html` with no build step, deployed on Vercel.

**Live site:** https://nikhil-vishwakarma-ai.vercel.app

## Projects featured

| Project | What it does | Code |
|---|---|---|
| Trade Finance Compliance Agent | LangGraph pipeline that cross-checks LC, invoice and B/L documents against UCP 600 rules, with a human-review step | [trade-finance-agent](https://github.com/Nikhil-029/trade-finance-agent) |
| Invoice to Accounting Sync Agent | OCR + LLM extraction with confidence scoring, human review and pluggable sync targets (live demo available) | [Invoice_Sync_Agent](https://github.com/Nikhil-029/Invoice_Sync_Agent) |
| AI Slide Deck Generator | Two-stage LLM pipeline that turns a PDF into a designed PowerPoint deck | [pdf-to-pptx-generator](https://github.com/Nikhil-029/pdf-to-pptx-generator) |
| YouTube Video Q&A | Transcribes a video and answers questions grounded in the transcript, with timestamps | [youtube-video-qa](https://github.com/Nikhil-029/youtube-video-qa) |
| Support Inbox Automation Agent | Classifies support emails and drafts replies from a knowledge base, auto-sending only the safe ones | [support-inbox-agent](https://github.com/Nikhil-029/support-inbox-agent) |

## Editing the site

All content lives in `index.html`. Edit the file (or replace it through
GitHub's Add file > Upload files) and commit to `main`; Vercel redeploys
automatically within a minute or two.
